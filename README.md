# active-directory-lab
Hands-on Active Directory lab documenting my work with Windows Server, virtual machines, networking, and troubleshooting

## Project Overview

This project documents my hands-on learning experience with Windows Server, Active Directory, and virtual machines. Through practical lab exercises, I am developing skills in operating system installation, network configuration, and troubleshooting. The goal of this project is to demonstrate my progress and build practical IT skills.

## Lab Environment

This lab environment was created using VMware Workstation Pro to run multiple virtual machines. The environment includes Windows Server and Windows 11 Pro, so I can practice networking, connectivity testing, and Windows administration.


**Current Virtual Machine Configuration:**

- **Virtualization Software:** VMware Workstation Pro
- **Virtual Machine 1:** Windows Server 2025
- **Virtual Machine 2:** Windows 11 Pro
- **Virtual Machine 3:** Windows 11 Pro
- **Total Virtual Machines:** 3

## Networking and Connectivity Testing

As part of my hands-on lab exercises, I practiced configuring IP addresses on virtual machines and testing network connectivity using the ping command in Windows Terminal. By changing IP address settings, I observed how network configuration affected communication between machines. After making the appropriate adjustments, I successfully received ping replies, confirming network connectivity.

## Active Directory Configuration

I installed and configured Active Directory Domain Services on Windows Server 2025 and joined two Windows 11 Pro virtual machines to the domain. Using Active Directory Users and Computers, I created four Organizational Units to organize different departments. This exercise helped me understand how Active Directory provides centralized management of computers and organizational resources.
